## Architecture (ASCII)

```
WA owner ──► Hermes kasir-pipe (allowlist)
               │
               ├─ stok/jual/… ──► kasir-tools ──► PostgREST/DB
               │
               └─ prefix tanya|konsultasi|pendamping
                    + tool kasir_consult (always registered)
                    │
                    ├─ KASIR_CONSULT=0 ──► user_safe “belum aktif”
                    └─ KASIR_CONSULT=1
                         ──► POST http://middleware:4001/internal/kasir-consult
                              Header: X-Kasir-Consult-Key
                              Body: { question }   (timeout 30s)
                              │
                              ├─ max ~500 char
                              ├─ notebookId from KASIR_CONSULT_NOTEBOOK_ID
                              ├─ retrieve top_k 4–6 (chunk-only path)
                              ├─ 0 chunks → miss copy (no LLM)
                              └─ synthesize via buildConsultFromNotebookPrompt
                                   → reply ≤800 char
                         ◄── user_safe wrap ──► WA
```

## Failure modes

| Failure | User sees | Test | Handling |
|---------|-----------|------|----------|
| Wrong/missing secret | Hermes error → busy copy | Nest 401 unit | Guard reject |
| Flag OFF | “belum aktif” | Hermes unit | No Nest call |
| Notebook unset / empty index | Miss copy | Nest miss unit | No free LLM |
| Retrieve 0 chunks | Miss copy | Nest miss unit | No free LLM |
| Nest/LLM timeout >30s | Busy copy | Hermes timeout unit | No retry |
| Nest 5xx | Busy copy | Hermes error path | Log `consult_error` |
| Question >500 char | Reject / trim copy | Nest max-len unit | Before retrieve |
| Model skips tool, answers free | Soft risk | SOUL + tool always present | Observe; not hard-gate text |
| `cek stok` routed to consult | Wrong answers | Smoke stok regression | SOUL + prefix discipline |

**Critical gaps:** none with D9 matrix + miss/error copies. Soft gap: SOUL-only routing if model ignores tool — accept for v1; watch in observe assignment.
